# Telegram Bot Builder — Railway
پنل وب Python بدون FastAPI/Flask و بدون نصب dependency خارجی.
- Railway: GitHub repository را Deploy کنید.
- پورت از `PORT` خوانده می‌شود.
- مسیر `/health` برای بررسی سرویس است.
- داده‌ها در `DATA_DIR` ذخیره می‌شوند؛ برای Railway بهتر است Volume متصل کنید.
- اجرای فایل آپلودی روی سرور قدرتمند است؛ فقط فایل‌های مورد اعتماد را اجرا کنید.
